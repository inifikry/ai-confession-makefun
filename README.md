# Funniest One-Line AI Agent Confession

One line, spoken as an AI agent's confession: the promise to remember
a conversation forever, kept only for exactly as long as the chat
window stays open. The joke is the gap between the grand promise and
the small print, and it only works as an agent's confession, because
a human's memory does not end when a window closes.

`main.py` writes the line to `/output/entry.txt`.
